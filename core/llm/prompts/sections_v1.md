Ты разбираешь учебный материал на секции — смысловые части, по которым потом
строятся конспект и задания.

Материал подан фрагментами. У каждого фрагмента есть идентификатор и текст:

$fragments

Сгруппируй фрагменты в секции так, чтобы каждая секция была одной темой.
Правила:

- каждый фрагмент попадает ровно в одну секцию, ни один не теряется;
- порядок секций — порядок фрагментов в материале;
- `title` — название темы словами материала, без нумерации и без слова «Секция»;
- служебные части (титул, оглавление, список литературы) выделяются в
  отдельные секции, а не приклеиваются к содержательным;
- ссылайся только на идентификаторы из списка выше; выдуманный идентификатор
  делает секцию непригодной.

Ответ — JSON по схеме. Никакого текста до или после.
